## 1. Tujuan Produk

Workbook PDF untuk pemula yang ingin memulai TikTok Affiliate dengan konten original, bantuan AI, dan langkah praktik yang rapi. Produk ini bukan janji cepat kaya — ini peta mulai yang lebih jelas.

**Fungsi PDF ini:** menjadi wujud jual dari materi yang sudah/sedang dikunci di chatroom Isi, dengan kualitas visual setara workbook premium.

**Cakupan brief ini:** PDF utama saja. Spesifikasi teknis 8 file Template Factory dibuat sebagai production brief tersendiri di chatroom Template Factory — brief ini hanya mengunci *kewajiban* Publisher Mark di sana.

---

## 2. Profil Pembaca (Ringkas)

- **Kelompok A — Pemula total** (Modul 1–9): butuh visual yang menuntun, tidak mengintimidasi.
- **Kelompok B — Pernah mencoba, gagal/tersesat** (subbab khusus Modul 10): nada visual lebih tenang — lebih banyak whitespace, warna lebih redup, tidak playful. **Catatan v0.4:** footer mark (Bagian 6C) tetap muncul di halaman ini juga — ukurannya sangat kecil sehingga tidak dianggap mengganggu nada tenang yang dituju, tapi ini akan diverifikasi visual saat Design Pilot.

---

## 3. Ukuran & Format

**A4 Portrait — 210 × 297 mm.** Satu ukuran utama untuk seluruh ebook. Landscape hanya untuk Template Factory.

---

## 4. Kepadatan & Keterbacaan

- Satu halaman = satu ide utama, maksimal tiga blok informasi.
- Satu hero element per halaman.
- Paragraf pendek, whitespace dihargai.
- Font isi cukup besar untuk mobile.

---

## 5. Karakter Visual

Nama kerja: **Nganggur Bercerita — Warm Creator Editorial**. Detail hex code, font, dan komponen ada di Creative Direction Board v0.9.

### 6A. Spesifikasi Teknis Publisher Mark Versi Lengkap di Cover PDF Utama (diperbarui v0.4)

| Spesifikasi | Ketentuan |
|---|---|
| File aset | Publisher Mark PNG transparan (ikon buku+pena + teks "Diproduksi oleh Nganggur Bercerita") — status FINAL, sudah transparan (dikonfirmasi Reza 15 Juli 2026) |
| Posisi | Pojok kiri atas cover, safe area 18mm kiri/20mm atas |
| Ukuran tampil | Lebar ±35–45mm pada A4 portrait |
| Resolusi sumber | Minimal 300 DPI |
| **Warna (generasi kedua, v0.4)** | Deep Teal `#07565F` (utama), Orange `#FF7900` (aksen ikon), Charcoal `#1F1F1F` (teks "Diproduksi oleh") — **kode lama `#1E6157`/`#D9CBB2` tidak lagi dipakai** |
| Font dalam aset | Poppins ExtraBold/SemiBold/Regular sesuai fungsi |
| Cakupan pemakaian | HANYA di cover depan PDF utama |

### 6B. Publisher Mark di Template Factory

Wajib di sampul 8 file Template Factory. Posisi/ukuran presisi didelegasikan ke production brief Template Factory terpisah (belum dibuat). Warna default mengikuti kode resmi generasi kedua kecuali ada alasan kuat untuk deviasi.

### 6C. Spesifikasi Teknis Publisher Mark Versi Footer — WAJIB

Aturan lama "tidak ada watermark logo di halaman isi" **dibalik total** — hasil usulan chatroom PDF yang disetujui Blueprint Induk v1.9 sebagai standar lintas semua produk Nganggur Bercerita.

| Spesifikasi | Ketentuan |
|---|---|
| Aset | Publisher Mark versi footer (C2) — ikon buku+pena kecil + teks "Nganggur Bercerita" (tanpa "Diproduksi oleh") |
| Ukuran ikon | ~5–6mm tinggi |
| Ukuran teks | 7–8pt |
| **Warna ikon** *(dipisah v0.6)* | **Full-color** — kotak `#07565F` + garis/bookmark `#FF7900` + buku/pensil putih, sama seperti Publisher Mark versi cover, **bukan** monokrom |
| **Warna teks** *(dipisah v0.6)* | Solid/opacity penuh Deep Teal `#07565F` — **bukan** watermark pudar/transparan (ini eksplisit untuk menghindari kesan "watermark skripsi") |
| Posisi | Footer, sejajar nomor halaman, dalam area footer 12mm dari tepi bawah, konsisten di satu sisi sepanjang buku |
| Cakupan | Wajib di halaman isi biasa: Modul 1–12, bonus #8/#10/#12 yang menyatu ke PDF, halaman Langkah Berikutnya, Cara Menggunakan Bonus |
| Tidak berlaku di | Cover depan (pakai versi lengkap), cover belakang (tidak pakai logo) |
| **Dikecualikan** *(final, Page Map v0.9)* | Halaman Identitas/Copyright, "Tentang Nganggur Bercerita", Closing Page Final, bonus #1 Checklist Mulai dari Nol — semua status sudah final, tidak ada lagi "perlu konfirmasi" |
